# 第二阶段最终定位：原版 App 为什么在 Mate50 上**必然崩溃**

> **本文档把"卡 88%"追到了根，并给出一个必须接受的结论。**
>
> 先前（`08-`）已确认是 OOM。本轮用**带 CER 授权的环境**（时钟设回 2019）
> 重新实测，定位到了精确的代码行与触发数据。

---

## 一、实验条件（这次是干净的）

| 条件 | 值 |
|---|---|
| 设备 | Mate50 Pro `DCO-AL00` / Android 12 / SDK 31 / **未 root** |
| 时钟 | **`Tue Oct 1 08:24 CST 2019`**（在 CER 的 `ValidPeriod` 窗口内） |
| `auto_time` | 0（手动） |
| 旅游必备 | 先装**原版**（未改动），后装改包版 —— 两者都测 |

### ★ 附带证实：CER 授权在 2019 时钟下**完全生效**

同一个原版 APK，只改变安装时的时钟：

| 权限 | 时钟 2026 时安装 | **时钟 2019 时安装** |
|---|---|---|
| `MDM_INSTALL_SYS_APP` | ❌ false | ✅ **true** |
| `MDM_APP_MANAGEMENT` | ❌ false | ✅ **true** |
| `MDM_DEVICE_MANAGER` | ❌（未申请） | ✅ **true** |
| `MDM_NETWORK_MANAGER` | ❌ | ✅ **true** |
| `MDM_PHONE_MANAGER` | ❌ | ✅ **true** |
| `MDM_VPN` | ❌ | ✅ **true** |
| `ACCESS_INTERFACE` | ❌ false | ✅ **true** |
| `MDM_INSTALL_UNDETACHABLE_APP` | ❌ false | ❌ false（清单里声明了但固件未定义） |

**唯一变量是时钟 ⇒ 八项特权权限全部授予。** 这是 CER 机制目前最干净的一次 A/B 证据。

## 三、精确到代码行：它给**已安装的 APK** 算 MD5

`com/x/plus/pro/update/c.smali` 的 `e(Context)`（私有，smali 行 815 起）——
这是在构造更新检查的请求体 `upg_params`：

```java
// UpdateImp.java  方法 e(Context) -> String
JSONArray arr = new JSONArray();

// 1) 先放自己的包信息
JSONObject self = new JSONObject();
self.put("name",         ctx.getPackageName());
self.put("version_name", PackageUtil.e(ctx, pkg));
self.put("version_code", PackageUtil.d(ctx, pkg));
arr.put(self);

// 2) ★ 再遍历清单里的每个 GMS 包
List<ApkInfo> list = c.a(ctx);              // smali:868  读 assets/Xpp_Q.json（本地，解密）
for (ApkInfo a : list) {                    // smali:882-891
    JSONObject o = new JSONObject();
    o.put("name",         a.d);                            // smali:906-910  包名
    o.put("version_name", PackageUtil.e(ctx, a.d));        // smali:914-922
    o.put("version_code", PackageUtil.d(ctx, a.d));        // smali:926-934
    o.put("md5",
        FileUtil.b(                                        // smali:946  ★ 算 MD5
            PackageUtil.f(ctx, a.d)                        // smali:942  ★ 已装 APK 的路径
        ));
    arr.put(o);
}
return arr.toString();
```

### 关键点

- `PackageUtil.f(ctx, pkgName)` 取的是**该包已安装的 APK 路径**，即 `/data/app/.../base.apk`
- `FileUtil.b(String)` 为了算 MD5，**把整个文件读进一个无上限增长的 `ByteArrayOutputStream`**
- 清单里第一个包是 `com.google.android.gms` —— 在 Mate50 上那是
  **86.5 MB**（甚至更大，因为 Play 商店升级到了 26.34.36）

⇒ 读入过程中 `ByteArrayOutputStream` 扩容到 **256 MB**，超过可用连续内存 ⇒ 崩溃。

**这段代码在构造 POST 请求体时同步执行，与网络是否可达无关，也与时钟无关。
所以只要 GMS 已安装且体积够大，App 每次启动都会死在这里。**

实测改包版（`旅游必备-patched.apk`）在 2019 时钟下：


**同一行、同一个分配量。** 因为第一阶段/第二阶段的补丁改的是：

| 已改 | 未改 |
|---|---|
| `NetworkUtil` 网络检查恒真 | ❌ **`FileUtil.b()` 的整包读入** |
| 安装方式改走系统安装器 | ❌ `UpdateImp.e()` 的 MD5 遍历 |
| `SDK_INT` 写死 29 | |

## 五、结论（必须接受的三条）

### ① 原版 App 在 Mate50 Pro 上**完全不可用**

不是"卡在某一步"，是**启动即崩**，且崩在更新检查的请求体构造阶段，
走不到下载、走不到安装。

### ② 改包是必需的，而且现有的补丁**还不够**

要让它可用，必须再把 `FileUtil.b(String)` 改成**流式分块 MD5**
（`FileInputStream` + 8 KB 缓冲 + `MessageDigest.update`，内存恒定）。

这是一个**几行的改动**，但必须动代码 ⇒ 必须重签 ⇒ `DeveloperKey` 失配 ⇒
CER 授权全部失效（第一阶段已实测 0/7）。

### ③ "免改包"的所有路线都已逐一排除

| 路线 | 结论 | 依据 |
|---|---|---|
| 预置 APK 到缓存 | ❌ 预检本身调 `FileUtil.b()`，同样 OOM | `Downloader.a` → `c/a.smali:67` |
| 预置到**内部**缓存 | ❌ 需 root（实测 `Permission denied`） | — |
| `run-as` 写内部缓存 | ❌ `package not debuggable` | 实测 |
| 加 `android:largeHeap` | ❌ 需重打包；且 manifest 已有该属性也无用 | — |
| 清空 App 数据 | ❌ 读的是 `/data/app/` 里的已装包 | 实测 `pm clear` 后仍崩 |

## 六、一个重要的好消息仍然成立

**CER 授权是真的有效** —— 2019 时钟下原版拿到了 8 项特权权限（含
`MDM_INSTALL_SYS_APP`）。也就是说：**如果 App 不崩，它确实有能力把 GMS 装成系统应用。**

⇒ 所以"修好 OOM 的改包版"与"用原版跑 CER 授权"是**互斥**的，但两条路各自都能达到目的：

| 路径 | 手段 | 代价 |
|---|---|---|
| A | 用原版跑 CER 授权 + 系统级静默安装 | **需要先解决 OOM，而动代码就毁授权**（死锁） |
| B | 用改包版做用户态安装向导 | 无 MDM 权限，但 **GMS 作为普通应用也能工作**（第一阶段已证实） |

**路径 B 是唯一自洽的。** 而第二阶段已确认它可行：
原版 APK 自带全部 GMS 包（5/5 MD5 匹配），改包版能把它解出来并交给系统安装器。

## 七、下一步的具体动作（建议）

把 `FileUtil.b(String)` 补成流式 MD5，具体是在 `travel_decoded` 的
`com/x/plus/pro/f/c.smali` 方法 `b(Ljava/lang/String;)Ljava/lang/String;`（smali 行 680）
里，把：

```smali
invoke-static {v2}, Lcom/x/plus/pro/f/c;->a(Ljava/io/File;)[B
```

改成调用一个新加的流式方法（或在 smali 里直接内联 `FileInputStream` 循环 +
`MessageDigest.update`）。这样：

- 改包版不再 OOM
- 但**仍然拿不到 MDM 权限**（DeveloperKey 失配）
- ⇒ 只能走路径 B，**这正是我们需要的**

**注意**：`FileUtil.b` 被 5 处调用（`ApkInfo:145`、`c/a:67`、`e/b$4:60`、
`update/c:717`、`update/c:946`），一次修好全部受益。
